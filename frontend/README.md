# ERPNext Priority Engine - Frontend

Next.js dashboard for ERPNext Priority Engine with TypeScript and Tailwind CSS.

## Setup

```bash
cd frontend
npm install
```

## Development

```bash
npm run dev
```

Visit http://localhost:3000

## Build

```bash
npm run build
npm start
```

## Environment Variables

Create `.env.local`:

```
NEXT_PUBLIC_API_URL=http://127.0.0.1:8000
```

## Features

- Dashboard with filter controls
- Real-time API integration
- Responsive table with invoice data
- Bar chart visualization with Recharts
- Loading and error state handling
- Tailwind CSS styling
